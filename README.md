# Operational KPI Dashboard

## Business Problem
This project analyzes operational incidents to improve service reliability, reduce downtime, and enhance incident resolution efficiency.

## Dataset
Operational incident data including department, severity, resolution time, and downtime.

## Tools Used
- Python (Pandas, Matplotlib, Seaborn)
- Power BI

## Key Insights
- Certain departments generate higher incident volumes.
- High-severity incidents contribute disproportionately to downtime.
- Resolution times vary significantly by incident type.

## Business Recommendations
- Prioritize preventive controls for high-severity incidents.
- Allocate resources to departments with recurring issues.
- Track KPIs continuously using dashboards.
